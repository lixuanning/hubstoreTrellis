# 测试用例 — AI 助手入口机器人 + 基础问答

> 来源: QA / 产品验收
> 版本: MVP v0.1
> 最后更新: 2026-08-12

---

## 冒烟测试（必须全部通过才可提测）

- [ ] 首页正常加载，浮动机器人按钮可见
- [ ] 点击机器人按钮，对话框弹出，无白屏/报错
- [ ] 输入文字发送，收到 AI 回复，不走 404
- [ ] H5 端对话框底部不被 TabBar 遮挡

---

## 功能测试

### 场景 1: 入口机器人

- [ ] 首页右下角显示浮动机器人按钮（40rpx 圆角，底部 200rpx）
- [ ] 点击按钮，弹出对话框，动画从底部滑入
- [ ] 对话框高度 70vh，圆角 24rpx
- [ ] 再次点击遮罩层或关闭按钮，对话框收起

### 场景 2: 基础问答 - 发送消息

- [ ] 输入框可用，placeholder 为"输入你的问题..."
- [ ] 输入文字"你好"，点击发送按钮
- [ ] 用户消息显示在对话区域右侧
- [ ] 出现"对方正在输入..."loading 态
- [ ] AI 回复显示在对话区域左侧，loading 消失
- [ ] 输入框在发送后清空
- [ ] 自动滚动到最新一条消息

### 场景 3: 边界与异常

- [ ] 输入纯空格点击发送 → 不允许发送（发送按钮置灰或 toast 提示）
- [ ] 网络断开时发送 → 提示"网络异常，请稍后重试"
- [ ] AI 返回格式异常 → 不崩溃，提示"回复异常，请重试"
- [ ] 连续快速点击发送 → 防抖，不重复发同一条
