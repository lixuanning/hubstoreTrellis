# 川西自驾 · 大交通决策存档（自驾全程 vs 落地租车）

> **存档日期：** 2026.8.31 · **对应路书：** 川西川渝自驾路书_v2_飞成都租宋pro_9.25-10.7.md（v2.8）
> **范围：** 只聚焦**大交通框架**这一个最高层决策（全程自驾 vs 高铁+落地租车）；**路书内部的决策**（党岭去留、车次、住宿、机动日等）由路书决定，不在本档。
> **口径：** 2 人 · 13 天（D0 9.25 ~ D12 10.7）

---

## 0. 一句话结论

**倾向：高铁 + 落地租车（成都进成都出）** —— 费用与全程自驾基本打平，但省 4 天赶路、免 5,170km 长途驾驶疲劳、磕碰全险兜底假期不断档。

---

## 1. 两案全景对比

### 1.1 两个方案是什么

| | **A. 全程自驾** | **B. 高铁 + 落地租车（当前方案）** |
|---|---|---|
| **怎么走** | 深圳开车 → 川西环线 → 开回深圳 | 高铁深圳↔成都（2 段往返）+ 成都东取还车自驾川西环线 |
| **总里程** | 往返约 3,800km + 川西 1,370km ≈ **5,170km** | 高铁约 2,600km + 落地自驾 1,370km |
| **驾驶强度** | 往返各约 2 天纯赶路（**多 4 天在路上**） | 高铁上可休息，落地即玩 |
| **车辆** | 自己的车 | 神州海狮 05 DMI（9 天） |

### 1.2 费用对比（2 人）

| 大项 | A. 全程自驾 | B. 高铁 + 落地租车 |
|---|---|---|
| **大交通** | 0 | **3,021**（G2244 去 1,480 + G2941 返 1,541） |
| **租车** | 0（用自己车） | **3,000**（9 天，含尊享百万全险） |
| **油费** | 约 **2,330-3,490**（按 6-9L/100km × 7.5 元/L） | 约 410-510（海狮 05 DMI 4-5L/100km × 1370km） |
| **过路费** | 约 **1,800**（高速约 4,000km × 0.45 元） | 270 |
| **折旧/保养/轮胎** | 约 **1,550-2,585**（按 0.3-0.5 元/km 用车成本） | 0（租车免折旧） |
| **合计** | **约 5,700-7,900** | **约 6,700-6,800** |
| **口径说明** | 油/过路按估算；折旧是隐性成本，不开车也存在不了 | 大交通 3,021 + 租车 3,000 + 油/过路 680-780 |

> 📌 **费用结论：两者基本打平。** 自驾表面便宜，但"省"的主要是把折旧/损耗隐形化了（5,170km 实打实跑在自己车上）。高铁+租车多花的钱换的是时间与省心。

### 1.3 非金钱维度

| 维度 | A. 全程自驾 | B. 高铁 + 落地租车 |
|---|---|---|
| **时间** | ❌ 往返各 2 天纯赶路 = **多花 4 天** | ✅ 高铁去 8h / 返 8h，不占游玩时间 |
| **体力/疲劳** | ❌ 单程 1,900km、往返 4 天长途，**累** | ✅ 高铁可休息，落地即玩 |
| **同行晕车** | ❌ 长途驾驶 + 山路颠簸，**同行的晕车遭罪**（女友易晕） | ✅ **高铁平稳晕车少**，落地自驾仅川西段；晕车药/靠窗缓解 |
| **住宿环境** | ❌ 车随人走，易走向**床车**（睡车里，无独立卫浴/热水） | ✅ **全程住酒店民宿**（独立卫浴+热水+大床），**环境完胜床车** |
| **装备转运** | ✅ 装备全程随车 | ⚠️ 曾是最痛点（高铁/地铁/打车转车）→ **已优化**：成都进成都出 + 成都东同城取还车，装备放后备箱全程不动 |
| **车辆磕碰** | ❌ 自己的车走保险：报险→定损→修车→影响下年保费，**假期中断** | ✅ 租车 + 全险，小磕碰 <5000 免材料直接走，**假期不断档** |
| **省心度** | ❌ 低（心疼车 + 保险流程繁琐） | ✅ 高（"性能最好的车是租的车"） |

### 1.4 决策依据（原话存档）

> - **"往返大交通开车太累"** —— 自驾最大的否决点（体力 + 时间）
> - **"背着一堆装备来回转车，高铁、地铁、打车到酒店，然后又租车……过程太麻烦"** —— 高铁方案的原痛点；**已通过"成都进成都出 + 同城取还车 + 砍重庆"解决**（装备全程不动）
> - **"租车行程里一两天开不了几公里，却要付出一天将近 400 的成本"** —— 对**租车天数**的成本敏感；属于方案 B 的可优化项（缩短租车天数/路线紧凑化），由路书层决定

### 1.5 结论

**主推 B（高铁 + 落地租车）**。只有当"完全接受 4 天长途驾驶 + 车辆损耗 + 磕碰走保险"时才选 A——与"省心玩透"的目标相悖。若某天真想自驾，费用上 A 并不占优（打平），仅赢在"装备全程随车"这一个点上。

## 2. 落地租车 vs 开自己的车（方案 B 的子决策）

| 维度 | 开自己的车（运/开到成都） | 落地租车（神州海狮 05 DMI） |
|---|---|---|
| **租车费** | 0 | **3,000**（9 天含全险） |
| **单程运车/开过去** | 1,900km（或托运 2,000-3,000 元） | 0（高铁直达成都东） |
| **非铺装应对** | 越野强但磕碰走保险流程 | 配 100 元/天尊享百万：**底盘/轮胎全赔，<5000 免材料** |
| **省油** | 视车型（6-9L/100km） | 海狮 05 DMI **4-5L/100km**（省 30%） |
| **V2L 外放电** | 视车型 | 海狮 3.3kW（应急够用） |
| **折旧/损耗** | 5,170km 实打实损耗在自己车上 | 0 |
| **车型/好开** | 豹 5 **硬派越野**（重心高、悬挂硬，城市/高速/铺装舒适性一般） | 海狮 05 **城市 SUV**（铺装 + 轻非铺装**更好开**；**同为比亚迪、车机基本一致**，上手快） |
| **车况熟悉度** | 自己的车 **100% 熟悉**（刹车/悬挂/习性全知道） | ⚠️ **租车车况未知**（里程/轮胎/刹车状态靠运气）——**唯一变量，可缓解** |
| **心态** | 爱惜、怕磕、走保险繁琐 | **敢开敢造不心疼** |

> 📌 **结论：** 落地租车多花约 3,000，换来全险省心 + 省油 + 不折旧 + 敢开。**车况是租车唯一的风险点**，但可缓解：① 提车时**绕车验车**（漆面/轮胎/刹车/仪表报警），有瑕疵当场要求换车；② 下单选**较新车辆**（神州可看车龄/里程）；③ **全险兜底**（尊享百万含车损/轮胎），车况引发的小毛病也走保障。**核心价值是心情和时间**——可理解为花 3,000 买 9 天免操心自驾。

## 3. 租车成本与保险（方案 B 的价值支撑）

### 3.1 租车费用演进

| 阶段 | 口径 | 9 天费用 |
|---|---|---|
| 初估 | 389 元/天 含 50 元/天尊享险 | 3,500 |
| 优惠券后（第一版理解） | 租金 3,000 + 100 元/天全险 900 | 3,900 |

> 📌 比初估**省 500**，且保险档位更高（三者 20 万→100 万、含轮胎、免 1500 免赔额）。

| 保障 | 额度 | 决策价值 |

| ⭐ 单方事故 <5000 | **免理赔材料** | 小磕碰直接走，不用交警/照片 |
| 全损/报废 | 承租人承担车价 20%（约 2.4-3 万，第三方全责免） | 概率低，知悉 |
| ⚠️ 换人驾驶 | **非承租人开车出险不赔** | 两人出行务必都登记为可驾人 |
| ⚠️ 免责 | 酒驾/无证/涉水二次启动/划痕/加错油/15 日内交材料 | 详见路书 5.3 |
